## 🇮🇩 Bahasa Indonesia

### Versi Lengkap (portfolio / case study)

**WAPHafiz — Aplikasi Hafalan Quran Keluarga**
*Peran: Squad Lead / Tech Lead*

WAPHafiz adalah aplikasi web full-stack yang membantu satu keluarga (10–20 orang) menghafal
Al-Quran secara terstruktur dengan metode pesantren **Sabak–Sabqi–Manzil**. Satu admin (kepala
keluarga) dapat memantau progress hafalan seluruh anggota, sementara tiap anggota mencatat hafalan
harian dan mengikuti jadwal muraja'ah yang ter-generate otomatis.

Sebagai **Squad Lead**, saya memimpin tim lintas fungsi dari product discovery hingga rilis:
menyusun PRD dan membekukan scope v1 agar tim fokus, memecah pekerjaan menjadi milestone mingguan,
merancang arsitektur sistem dan kontrak API, melakukan code review, serta menjaga kualitas lewat
target coverage backend ≥ 80% dan integration test untuk alur kritis (register → login → hafalan →
muraja'ah).

Kontribusi & tanggung jawab utama:
- **Kepemimpinan teknis** — menetapkan standar engineering (konvensi commit, struktur monorepo,
  design system), dan menjadi penengah keputusan arsitektur.
- **Arsitektur** — mendesain sistem muraja'ah otomatis (Sabqi 7 hari terakhir + Manzil siklus 7 hari),
  serta proxy & cache Quran API (alquran.cloud) di Redis dengan TTL 24 jam.
- **Delivery** — mengelola roadmap, mencegah scope creep dengan membekukan fitur v1, dan memastikan
  rilis tepat waktu untuk pengguna internal keluarga.

**Stack:** Go · Fiber v2 · GORM · PostgreSQL · Redis · Nuxt 3 (Vue 3) · Tailwind · Pinia · JWT (RBAC) · Docker

## 🇬🇧 English

### Full Version (portfolio / case study)

**WAPHafiz — Family Quran Memorization App**
*Role: Squad Lead / Tech Lead*

WAPHafiz is a full-stack web application that helps a single family (10–20 people) memorize the
Quran in a structured way using the traditional pesantren method of **Sabak–Sabqi–Manzil**. One
admin (head of the family) can monitor every member's memorization progress, while each member logs
their daily memorization and follows an automatically generated revision (muraja'ah) schedule.

As **Squad Lead**, I drove the cross-functional team from product discovery to release: I authored
the PRD and froze the v1 scope to keep the team focused, broke the work into weekly milestones,
designed the system architecture and API contracts, ran code reviews, and enforced quality via an
80%+ backend coverage target and integration tests for the critical flow (register → login →
memorization → revision).

Key responsibilities & contributions:
- **Technical leadership** — set engineering standards (commit conventions, monorepo structure,
  design system) and owned key architecture decisions.
- **Architecture** — designed the automatic revision system (Sabqi for the last 7 days + Manzil on
  a rolling 7-day cycle) and a Quran API proxy/cache (alquran.cloud) on Redis with a 24-hour TTL.
- **Delivery** — managed the roadmap, prevented scope creep by freezing v1 features, and shipped on
  time for internal family users.

**Stack:** Go · Fiber v2 · GORM · PostgreSQL · Redis · Nuxt 3 (Vue 3) · Tailwind · Pinia · JWT (RBAC) · Docker
