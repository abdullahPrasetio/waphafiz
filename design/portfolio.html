Fitur Utama
Semua yang dibutuhkan keluarga penghafal Quran

Dibangun dengan fokus pada penggunaan harian yang simpel namun sistematis.

Autentikasi Keluarga
Register via kode undangan eksklusif. Tidak ada registrasi terbuka — hanya anggota keluarga yang bisa masuk. Role admin dan member dengan JWT RBAC.
Tracker Hafalan (Sabak)
Catat hafalan baru per ayat atau rentang ayat dengan status belum/sedang/hafal. Riwayat hafalan harian tersimpan otomatis.
Muraja'ah Otomatis
Jadwal Sabqi (hafalan 7 hari terakhir) dan Manzil (seluruh hafalan lama dalam siklus 7 hari) di-generate otomatis setiap hari.
Audio Quran
Playback audio per ayat dari alquran.cloud. Pilihan qori populer. Cache Redis 24 jam untuk menghemat bandwidth dan meningkatkan kecepatan.
Dashboard Progress
Admin bisa melihat progress hafalan seluruh anggota dalam satu halaman. Member melihat progress pribadi dan streak hafalan harian.
Manajemen Admin
Admin kelola anggota, lihat last-seen, generate ulang invite code, dan aktif/nonaktifkan member. Tabel progress semua anggota sekilas pandang.

Copy-paste untuk LinkedIn / portfolio site
Bahasa Indonesia
WAPHafiz adalah aplikasi web full-stack untuk membantu keluarga menghafal Al-Quran secara terstruktur. Dibangun dengan Go (Fiber v2) di backend dan Nuxt 3 (Vue 3) di frontend, aplikasi ini menerapkan metode hafalan pesantren Sabak–Sabqi–Manzil secara digital.

Fitur utama meliputi sistem muraja'ah otomatis (jadwal harian di-generate berdasarkan riwayat hafalan), tracker hafalan per ayat dengan status granular, audio Quran terintegrasi via proxy backend dengan cache Redis 24 jam, dan admin dashboard untuk memantau progress seluruh anggota keluarga.

Autentikasi menggunakan JWT HS256 dengan RBAC (admin/member) dan sistem invite code agar akses tetap privat untuk keluarga. Stack lengkap: Go · Fiber · GORM · PostgreSQL · Redis · Nuxt 3 · Tailwind · Docker.
English
WAPHafiz is a full-stack web application for families to memorize the Quran in a structured, systematic way. Built with Go (Fiber v2) on the backend and Nuxt 3 (Vue 3) on the frontend, it digitizes the traditional pesantren memorization method of Sabak–Sabqi–Manzil.

Key features include an automatic daily muraja'ah (revision) scheduling system, per-verse memorization tracking with granular status, integrated Quran audio playback via a backend proxy with 24-hour Redis caching, and an admin dashboard for monitoring all family members' progress.

Authentication uses JWT HS256 with RBAC (admin/member roles) and a family invite code system to keep the app private. Full stack: Go · Fiber · GORM · PostgreSQL · Redis · Nuxt 3 · Tailwind · Docker.
